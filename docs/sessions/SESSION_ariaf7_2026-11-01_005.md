## Decisions

- Callable name `resolveMembershipV1` (maintainer left naming to us); JoinCompany schemas removed rather than versioned because the endpoint was never deployed (ADR 0007).
- Personal-domain, provider and verification checks run before the rate limit and before any read; unmapped domains consume the budget.
- Display name refreshes from the token on later resolutions only when it changed (single-field server update).
- iOS: the session resolves membership automatically once per identity; no-company outcomes are a dedicated state that never grants tenant data; a cancelled Google sheet is not an error.
- Firebase attaches only with local `GoogleService-Info.plist` + `ui/Config/Local.xcconfig`; emulator routing is Debug-only and opt-in (`DIP_USE_EMULATORS=1`).
- Shared files (contracts, rules, lockfile, project.yml, CI-adjacent docs) changed in this PR at the maintainer's direction; flagged for sandervonk's review as integrator.
