## Member event-read integration (local branch, November 3)

Configured member accounts now construct a UID/company-scoped MemberEventsRepository through FirebaseBootstrap and bridge it into the existing Home/detail navigation with MemberEventAppRepository. The real read path supports bounded pagination, pull-to-refresh and observed selected-detail updates; it does not mix live company events with DIPMockData. Unconfigured Debug accounts and the standalone preview host retain the original fixture experience. Account profile/sign-out behavior is preserved.

This branch adds emulator-tested same-company event get/list rules and the matching companyId/status/startTime index definition. These changes are not deployed. A production client requires the reviewed rules and index to be deployed separately before these reads work there. Live RSVP commands, My Events and attendee/social adapters remain unconnected; the configured UI explicitly reports those actions as unavailable. Event images use a neutral placeholder while an approved catalog is pending. The admin portal belongs to Sander and is unchanged.
