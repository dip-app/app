# Weekly theme accent backgrounds

Art files are transparent (730x539, same slot as `fitness.png`); the card draws the solid accent behind them.
Use these hex values as each theme's `accent`. The title sits bottom-left: use ink text on yellow, green and blue backgrounds and white on ink, purple and pink; check coral (kindness) when wiring.

| key | background hex | note |
| --- | --- | --- |
| fitness | #FB72E4 | existing (`challengeAccent` pink) |
| sleep | #1E212B | ink |
| hydration | #7B88FA | purple |
| mindfulness | #FFCC3E | yellow |
| outdoors | #6BFF9B | green from the Fitness confetti |
| kindness | #FF7C73 | coral from the Fitness headband |
| learning | #66D9FF | blue from the Fitness blob |
| creativity | #FB72E4 | pink (same as Fitness, never adjacent in picker order) |
| cooking | #FFCC3E | yellow (same as Mindfulness, not adjacent) |

iOS image sets (Home.xcassets): `Mascot` is Fitness; the new ones are `MascotSleep`, `MascotHydration`, `MascotMindfulness`, `MascotOutdoors`, `MascotKindness`, `MascotLearning`, `MascotCreativity`, `MascotCooking`.
