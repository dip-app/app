# iOS workspace

Install Xcode and XcodeGen (`brew install xcodegen`). From the repository root run `npm run ios:generate`, then open `ui/DIP.xcodeproj` and choose the DIP scheme. Commit `project.yml`, not generated project files. This avoids shared project-file conflicts. The target is iOS 17+, Swift 6; the minimum OS and final bundle identifier are proposed team decisions. Set your signing team locally in Xcode for device runs.

The app currently renders a connected local SwiftUI prototype matching the supplied Figma frames. Firebase packages are declared, but initialization, account flows and repositories remain unimplemented. Presentation fixtures do not write live data. Copy the correct environment's GoogleService-Info.plist locally when a project is selected; do not commit it or service account credentials. Add initialization and emulator selection together in the first integration PR. Emulator host is 127.0.0.1 on Simulator; physical devices need the laptop LAN address. Never connect a development build to production by default.

`DIPContracts` contains generated Foundation DTOs. `DIPDesignSystem` contains token foundations. Both packages test independently of an iPhone simulator. JSON dates use ISO 8601 UTC; Firestore persistence uses Timestamp via explicit adapters to be implemented in Data. Document IDs belong to snapshot metadata; optional `id` is injected by the adapter and is not a Firestore field.

Use feature ViewModels and injectable repository protocols. Views render state and delegate actions; Firebase access lives in Data. Define the protocol and mock fixture together before separate agents build UI and adapters. Do not invent endpoints or duplicate shared tokens.

Full simulator build after generation: `xcodebuild -project ui/DIP.xcodeproj -scheme DIP -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build`. Full app tests: choose an available iPhone simulator using `xcodebuild -showdestinations`, then pass its destination to `xcodebuild test`. The isolated preview host runs eight simulator tests for the gallery, Home and connected prototype flows; see ComponentPreview/README.md. Product integration tests remain separate work.
