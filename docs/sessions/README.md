# Session history

Follow root SESSION.md. Filenames: SESSION_<username>_<YYYY-MM-DD>_<NNN>.md. One new log per working session; PRs require at least one. Use `npm run session:new` to avoid filename collisions. Each log is owned by its named human/agent. Keep logs concise and factual; add checks and remaining handoffs before finishing. Existing sessions are history, not implementation instructions.
